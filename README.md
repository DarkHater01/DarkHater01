## 🛡️ Sobre mí

Pentester, desarrollador backend y administrador de sistemas. **Licenciado en Ciencias de la Computación** con 2+ años de experiencia profesional real:

- 🔐 **Ciberseguridad ofensiva y defensiva** — auditorías de seguridad a un exchange de criptomonedas, hardening perimetral (firewalls, IDS/IPS) y concienciación de usuarios.
- ☕ **Backend y arquitectura de microservicios** — Spring Boot y Scala, APIs RESTful con arquitectura limpia, contenedores en Docker/Kubernetes y pipelines CI/CD con GitHub Actions y Jenkins.
- 🔍 **OSINT y automatización** — herramientas propias de recolección pasiva de inteligencia y monitorización de filtraciones en la Dark Web.
- 🧪 **Evaluación de agentes IA** — no solo si un agente acierta, sino **cuánto desperdicia** al hacerlo: código tirado y tokens tirados, medidos y publicados.

Creo herramientas para resolver problemas reales, no para llenar un portafolio: lo que subo a GitHub lo uso en mi día a día.

## 🧭 Cómo trabajo

- **Los números los genera un script, no la mano.** Si un dato aparece en un repo mío, sale de un run real y reproducible; si el run no pasó, el número no se publica.
- **Sandbox antes que confianza.** El código de un agente corre aislado, sin red y con el reporte de tests fuera de su alcance: un resultado que no se puede auditar no vale.
- **La métrica es contestable.** Si la base de comparación está mal, se arregla en un PR con argumentos — incluido el mío.
